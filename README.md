# Sahithi Pondugula — Makeup Artist Portfolio

A cinematic, editorial makeup artist portfolio built with Astro 6, semantic HTML, CSS and lightweight browser JavaScript.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Included

- Astro 6 architecture
- Responsive editorial layout
- Burgundy / ivory luxury visual system
- Native image hover interactions
- Context-aware desktop cursor
- Portfolio category filtering
- Fullscreen accessible lightbox with keyboard controls
- Scroll reveal and restrained parallax
- Mobile navigation
- Reduced-motion support
- SEO metadata
- Optimized WebP assets extracted from the supplied PDF

## Source content

All personal/contact details and portfolio photography were taken from the supplied `MAKEUP BY SAHITHI.pdf`. No client names, awards, locations, prices or other unsupported claims were invented.
